redcrab

A fast, native Redis and Valkey client for your Mac.

Browse millions of keys, edit every type, run commands and watch your servers, in an app drawn by the GPU. No Electron, no web view.

Download for Mac Source on GitHub

Free and open source. Or with Homebrew: brew install --cask muratmirgun/tap/redcrab
Requires macOS 11 or later, on Apple silicon or Intel. Coming soon to the Mac App Store.

Keys

Instant on millions of keys.

Keys stream in with SCAN, never KEYS *, into a folder tree split on :. Only the rows on screen are drawn. Strings, hashes, lists, sets, sorted sets, streams and JSON are paged however big they are, and edited in place.

Console

A real console.

A connection of its own, history, and completion of every command and its options, with the rest of the syntax greyed out as you type. ⌘J opens it anywhere.

Server

Watch the server.

Ops per second, memory, clients and hit rate as they change. The slow log, the connected clients, and INFO, all a keystroke away.

Memory

See what takes the memory.

By type, by key prefix, and the hundred biggest keys. Measure every key, or a sample of a huge database, and stop whenever you like.

Pub/Sub

Listen in.

Subscribe to channels and patterns, publish messages, and watch every command the server runs with MONITOR.

Everything around it.

Small things that make a client you can leave open all day.

Any way in

Standalone, Cluster and Sentinel. TLS and mutual TLS, SSH tunnels. Redis 6 and later, and Valkey.

Careful with production

Read-only connections enforced in the core, colored environment tags, and edits that never overwrite a value that changed meanwhile.

Passwords in the Keychain

Connections are saved on your Mac; passwords and passphrases go to the macOS Keychain, never to a file.

Values, decoded

Text, JSON, hex, or decoded from Base64, MessagePack and gzip, and saved back the way they came.

Keyboard first

⌘K opens a palette of everything the window can do, by name, with its shortcut.

Native and light

Written in Rust and drawn by the GPU. It starts at once and stays small, however many keys you open.

Light and dark

Follows your Mac's appearance, or pick one.

Nothing collected

No account, no analytics, no tracking. It talks only to the servers you set up.

Open source

MIT or Apache-2.0. Read it, build it, send a fix.

In the terminal, too.

redcrab-tui is the same app for a server you reach over SSH: the same saved connections and views, with vim keys. brew install muratmirgun/tap/redcrab-tui
